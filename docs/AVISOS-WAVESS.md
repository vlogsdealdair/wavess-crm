# Avisos WAVESS
Configuración → Avisos internos por Telegram. Crea un bot exclusivo en BotFather con /newbot, agrégalo a un grupo privado y escribe /wavess allí. Pega el token en el campo privado del CRM, detecta y selecciona el grupo, luego conecta. Al conectar se enviará una prueba y se avisará de los pedidos actuales listos. Token cifrado en Supabase Vault, sin acceso desde la interfaz.
Pago completo avisa si aún falta producto o destino. Listo para despachar exige producto recibido, saldo cero y destino completo; se avisa una sola vez por pedido. Cambios posteriores no vuelven a enviar el mismo aviso. En Despachos → Configurar entrega programa la fecha. A partir de las 09:00 Ecuador se recuerda una vez al día mientras el pedido esté listo y no despachado. Sin fecha no hay recordatorio.
Cron procesa cada minuto, incluso con CRM cerrado. Últimos avisos muestra pendiente/enviando/enviado/falló/sin confirmar/omitido. No reenvía automáticamente fallos ambiguos para evitar duplicados. Antes de reintentar un envío sin confirmar, revisa el grupo. Al pausar se detienen envíos; al reactivar se conservan pendientes.
WhatsApp en cada tarjeta de Despachos ofrece confirmación de pago, coordinación de entrega y aviso de envío según estado real. Abre chat del cliente con mensaje preparado; el operador lo revisa y envía. No automatiza mensajes al cliente ni usa API empresarial. Teléfonos ecuatorianos 09… se convierten a 593; otros requieren código internacional.
El token no se incluye en logs de aplicación ni respuestas. Vault y cola de red requieren acceso administrativo de base de datos. RLS limita historial al propietario. Funciones privilegiadas están en esquema privado y las operaciones públicas validan identidad por auth.uid().

Si Telegram no muestra el grupo al detectar, usa Conectar con enlace de Telegram Web. Copia la URL del grupo abierto en web.telegram.org. El CRM valida el grupo por getChat y rechaza grupos públicos.
